# Snapshot Contents

This directory freezes the approved 2026-08-22 baseline before the next UI/UX optimization phase.

## Folders

- `haf-energy-journey-h5/`: the embedded mobile H5, domain Skills, docs and built output
- `haf-energy-dashboard/`: the standalone lightweight analytics dashboard and collector

## Restore guidance

Do not run future edits directly inside this snapshot. To restore it, copy the required project folder to a new working directory, install dependencies from its lockfile, and verify the runtime/build before replacing any active deployment.

The dashboard snapshot contains no user or test event data.
