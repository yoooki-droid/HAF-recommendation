# 下一轮 UI/UX 优化基线

## 目标

下一轮可以继续提升视觉精度、可读性、仪式感和操作反馈，但不能破坏当前已经验证的流程与数据行为。

## 当前必须保留

- H5 为小程序首页内嵌模块，高度约 700px
- 整体左右贴边，无外层圆角框
- 蓝色主氛围与少量暖橙光流
- 回访页为纯文字问候，不重新加入大能量球
- 每日问候只使用 Personal Day 已知信息
- 罗盘仍是一次直接的手指感应，不恢复重复问题
- 结算页同时保留今日主旋律、此刻入口、能量落点和今日能量总结
- 推荐恰好三节课，横向浏览，有小图、契合理由、时长/形式和收藏
- 独立收藏页必须保留
- “重新感应”返回现有罗盘，不新建重复页面层级
- 埋点与接口失败不能阻断体验

## 可优先优化的方向

### 1. 首次建档

- 减少信息密度
- 明确哪些字段真正参与计算
- 提升生日选择的直觉性
- 把隐私说明变得更温柔、更短

### 2. 每日问候

- 检查 1–9 的文案节奏是否同一品牌声音
- 为每个数字增加三组稳定轮换句，避免九天后机械重复
- 优化主句断行和进入动画

### 3. 罗盘

- 增强手指落点和光球被吸引过去的感受
- 优化四个方向词的可读性
- 让“完成感应”在用户真正触碰后再明显出现

### 4. 合成动画

- 保持无矩形遮罩
- 更清楚地表现数字、脉轮和此刻能量正在靠近
- 控制在约 1.5 秒内，避免等待感

### 5. 结算页

- 优化信息层级与留白
- 检查三条能量线索是否一眼可读
- 让今日总结更像一句真正属于用户的话
- 保证课程理由在小屏宽度下仍然舒适

### 6. 收藏页

- 增强“收藏正在形成个人路径”的感受
- 保持不催促购买
- 为未来课程详情入口预留清晰位置

## 暂不扩大范围

- 不增加复杂问卷
- 不增加购买价格与销售压力
- 不增加脉轮诊断或健康结论
- 不把数据看板扩成复杂运营后台
- 不在 UI/UX 优化阶段改动算法权重

## 每轮验收

每次 UI/UX 修改后都需要重新走完：

```text
回访问候 → 罗盘 → 合成 → 结算 → 收藏 → 收藏页 → 返回 → 重新感应 → 第二次结算
```

并检查 H5 访问与一次收藏在看板中只增加一次。
