# HAF 探索本心：QA、快照与发布清单

版本：v3.0  
日期：2026-08-23

## 1. 自动检查

```bash
npm run check:runtime
npm run build
npm run test:sites
node --check ../haf-energy-dashboard/server.mjs
```

`npm run test:runtime` 需要本机 Playwright Chromium；若缺失，记录环境限制，不将它误报为产品失败。

## 2. 首次流程

- Loading 无矩形遮罩或异常透明块
- 三步介绍说明天生线索、此刻感应、今日回响
- CTA、隐私说明和输出承诺在 700px 内完整可见
- 6 月 29 日等日期可选，闰年 2 月 29 日可选
- 城市可自由输入并保存
- 保存后进入罗盘

## 3. 回访与缓存

- 回访不重复建档
- 问候在 Loading 中准备，页面出现后不跳字
- AI 超过 6 秒时使用本地问候且不在页面内重试
- 修改生日使 Life Path 或 Personal Day 变化时，不复用旧问候
- 同一用户、日期、Personal Day、Life Path 和表达切面命中稳定缓存
- 新自然日产生新的问候签名

## 4. 罗盘与结算

- 光点可点击与拖动
- 四个方向与坐标语义一致
- 向外/行动与向内/安静两组结果可观察到主脉轮、解读或课程差异
- 合成 Loading 中完成 AI 请求
- 结算页出现后解读文字、位置和高度保持稳定
- 标题最大不超过 24px，普通内容 14px，非课程卡最小 12px
- 结果引导句使用完整宽度，不出现单个汉字孤行
- 光球无矩形背景遮罩

## 5. 课程与收藏

- 恰好三张课程卡
- 每张有图片、名称、契合理由、时长/形式和收藏按钮
- 不显示价格或购买压力
- 收藏和取消收藏状态正确
- “已收藏 N”进入独立收藏页
- “重新感应”返回已有罗盘，不形成死循环

## 6. 接口与看板

- AI Key 不出现在 H5 构建产物
- AI 接口不接收生日、性别、城市
- 页面在 4174 不可用时仍可完成
- 一次模块打开只记录一次访问事件
- 一次成功收藏只记录一次收藏事件
- 看板访问用户、收藏用户和收藏总量可抽样核对

## 7. 快照规则

- 快照目录使用 `YYYY-MM-DD-名称-vN`
- 包含 H5 源码、锁文件、资产、Skills、docs、QA 证据和后端源码
- 排除 `node_modules`、`dist`、`test-results`、`.env.local`、`data/*.jsonl`、系统文件和临时日志
- 快照根目录必须有 README，说明范围、校验值和恢复方法
- 快照创建后只读，不在其中继续开发
