# 探索本心：连续交互 V1

## 核心目标

让用户先理解自己，再主动选择想靠近的状态。课程不是“修复用户”的商品，而是支持用户靠近自选方向的一次具体体验。

## 五步流程

### 1. 定位当下

- 用户拖动光点，在“向内独处 / 向外连接”和“安静沉淀 / 唤醒活力”两个维度上表达当下状态。
- 光点移动时，下方反思文案即时变化。
- 允许切换到简化选择模式，避免拖拽交互成为障碍。

### 2. 看见当下

- 免费给出一条主反思和两条观察。
- 明确说明“这不是评判，只是此刻的一个位置”。
- 此时不出现课程、价格或购买入口。

### 3. 选择向往

- 保留代表“此刻”的光点，让用户放置第二个代表“向往”的光点。
- 用一条柔和路径连接两点，并实时描述用户主动选择的变化方向。
- 用户可以稍后再看，不强迫完成。

### 4. 形成探索路径

- 将两点之间的距离转译为 2–3 个可理解的探索步骤。
- 示例路径：安定身体 → 听见内在 → 温和连接。
- 明确说明路径不是套餐，用户可以只选择其中一步。
- 这是多课程需求产生的位置：不是“买得越多越好”，而是不同体验承担不同阶段的作用。

### 5. 推荐第一步

- 首屏只推荐一个最适合当前阶段的体验，降低选择压力。
- 解释“为什么适合此刻的你”，同时展示时间、地点、导师、时长和价格。
- 主操作：预留这次体验。
- 次操作：先收藏，稍后决定。
- 提供“看看路径中的其他体验”，但不默认捆绑购买。

## 转化原则

1. 先提供免费价值，再出现商品。
2. 由用户定义“当前状态”和“向往状态”，系统只负责解释路径。
3. 推荐理由必须能被用户看懂，并与前面的选择一一对应。
4. 不使用倒计时、稀缺性、羞耻、恐惧或夸大疗愈效果推动购买。
5. 收藏、加入路径和购买是三个不同意图，不混用。
6. 单次体验始终可买；完整路径是建议，不是强制套餐。

## 建议埋点

- 开始定位
- 完成当下定位
- 查看状态反馈
- 设置向往状态
- 生成探索路径
- 查看第一步体验
- 收藏体验
- 查看其他路径体验
- 发起购买
- 完成购买

重点观察“看见当下 → 选择向往”和“探索路径 → 查看体验”两段转化，不只看最终支付率。
