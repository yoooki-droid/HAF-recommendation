# HAF 探索本心：当前系统架构

版本：v3.0  
日期：2026-08-23

## 1. 组成

| 模块 | 当前职责 | 位置 |
| --- | --- | --- |
| 内嵌 H5 | 建档、共鸣词感应、结果、课程、收藏、前端缓存 | `haf-energy-journey-h5` |
| 规则引擎 | 灵数、脉轮投影、能量合成、课程排序 | H5 的领域 Skill 与运行时代码 |
| Demo 后端 | DeepSeek 问候/解读、最小埋点、聚合接口 | `haf-energy-dashboard/server.mjs` |
| 数据看板 | 访问、收藏用户、收藏总量、课程明细 | `haf-energy-dashboard` |

## 2. 首次流程

```text
Loading
  ↓
三步玩法介绍
  ↓
一次性建档（生日、可选信息、城市）
  ↓
隐藏词场中选择一个共鸣词
  ↓
规则层计算数字、选词对应的主脉轮与支持性次脉轮
  ↓
合成 Loading 同时请求 AI 解读
  ↓ 最长 6 秒
AI 解读或本地解读被锁定
  ↓
结果 + 三节课程 + 收藏
```

## 3. 回访流程

```text
Loading 同时计算 Personal Day 并请求每日问候
  ↓ 最长 6 秒
AI 问候或本地问候被锁定
  ↓
文字问候 → 共鸣词感应 → 合成 → 结果
```

## 4. 规则层

### Numerology

- `life_path`：完整生日的数字归并结果，可保留 11、22、33。
- `personal_day`：出生月日与当前自然日期组合后归并为 1–9。
- 页面当前统一用“灵数”作为轻量展示，不在本版本调整命名。
- `今日灵数` 展示的是 `personal_day`，不是 `life_path`。v2 展示词为：1 开始、2 连接、3 表达、4 安定、5 变化、6 关怀、7 内省、8 实现、9 完成。
- 数字展示词与脉轮词是两层语言；数字只提供今日节律和辅助权重，不直接等于某个脉轮。

### Word resonance field

- 感应面是隐藏的 7 列 × 10 行词场，共 70 个词，每个脉轮十个。
- 坐标只负责寻址，不代表上下、左右或四种性格方向。
- 时间不会轮播词；只有进入新的位置单元才换词，松手锁定当前词。

### Chakra projection

```text
70% 用户选词 + 20% 生命路径亲和度 + 10% Personal Day 亲和度
```

输出七个相对信号、主脉轮、次脉轮和解释主题。它是 HAF 版本化反思模型，不是生理检测。

### Energy synthesis

- `今日主旋律` 来自 Personal Day。
- `当下共鸣` 来自用户锁定的词。
- `能量落点` 直接来自该词所属的脉轮。
- 本地规则先生成可用总结，AI 只润色语言。

### Course recommendation

当前打分：

```text
50% 脉轮 + 20% 选词标签 + 10% 今日灵数 + 10% 练习适配 + 10% 新鲜度
```

结果必须为三节已发布课程，并对形式和主要标签做轻量多样性约束。

课程关键词从标题、简介和官方标签独立识别；`numerology_tags` 只进入 10% 今日灵数项，不得再转换成关键词后重复进入 20% 选词标签项。

## 5. AI 调用

DeepSeek 不参与任何数字、选词、脉轮或课程事实计算。

### 每日问候

输入：匿名用户键、日期、Personal Day、主题、生命路径数、每日表达切面、最近 30 条问候。  
输出：14–30 个中文字符的一句话。

### 能量解读

输入：匿名用户键、日期、今日主题、用户选词、主次脉轮名称与主题。
输出：18–50 个中文字符，最多两句。

## 6. 缓存与稳定性

### 前端每日问候键

```text
v2 + date + personal_day + life_path
```

每日表达切面由日期和匿名用户键稳定选取。后端缓存还包含用户、日期、Personal Day、Life Path 和表达切面。

### 前端能量解读键

```text
date + personal_day + selected_word_id
+ primary_chakra + secondary_chakra
```

### 超时行为

1. 前端统一 6 秒后中止请求。
2. 非法长度、非 2xx、解析失败或超时都选择本地兜底。
3. 兜底也写入当前签名缓存，因此进入展示页后不会重试。
4. 同签名并发请求由内存 Promise 合并。
5. 页面出现后不再替换文案，避免跳动。

## 7. 当前存储

| 数据 | Demo 存储 |
| --- | --- |
| 用户建档 | 浏览器 localStorage |
| 匿名用户键 | 浏览器 localStorage |
| AI 问候/解读 | 浏览器 localStorage + 后端进程内存 |
| 收藏 | 浏览器 localStorage |
| 访问与收藏事件 | 后端 `data/events.jsonl` |

正式上线时必须替换为 HAF 用户服务、课程服务、收藏服务、数据库缓存和有权限的数据看板。
