# HAF 课程可用性与召回规则

版本：0.2（2025 回溯验证）  
日期：2026-08-24

## 1. 两类问题分开判断

课程推荐前先判断“能不能推荐”，再判断“适不适合用户”。课程年份不直接代表上下架。

### 课程是否仍存在

1. 每次推荐开始前刷新课程列表。
2. 只有列表请求成功并确认返回完整数据时，缺失的课程才标记为下架。
3. 列表请求超时、网络失败或返回异常时，沿用上一份成功目录；不能把全部课程判为下架。
4. 当前 MVP 到此即可判断课程是否存在。课程 ID 详情接口保留为后续更严格校验能力：

```text
GET /organizer/suggestionInfo?elementId={elementId}
headers: appId=at_one_festival, lang=zh
```

5. 后续启用详情校验时，`status=0` 且 `data.detail.elementId` 一致表示内容仍存在；业务状态 `1103` 表示内容不存在。
6. 详情请求自身超时不等于下架，不能写入永久下架状态。

### 场次此刻是否可参加

1. 活动进行中，`endDatetime <= now` 的场次不再推荐。
2. 同一课程有多个场次时，只要还有一个未结束场次，课程仍可推荐。
3. 卡片展示最近的未结束场次；已经结束的旧场次不再展示。
4. 活动年份只用于目录和统计，不直接作为过滤条件。

### 当前 MVP 可用性规则

当前阶段只使用两个硬条件：

1. 课程仍在最新一次成功返回的完整列表中；
2. 至少有一个场次的 `endDatetime > now`。

库存、商品 ID、购买链接暂时只记录，不参与过滤。

### 后续库存规则（接口补齐后启用）

未来接口能稳定返回售卖状态和库存后，以下任一条件成立时排除场次：

- `ticketInfo.isShow=false`；
- 明确的 `soldOut=true`；
- 库存为明确数字且 `inventory <= 0`；
- 付费课程标记为“购买课程”，但详情中没有可用购买链接；
- 后台返回明确的停售、下架或不可购买状态。

库存字段为空表示“未知”，不能当成 0。当前 2025 数据的 254 个场次库存均为空，无法严格判断售罄；正式课程接口应补充以下任一字段：

```json
{
  "saleStatus": "on_sale | sold_out | off_sale",
  "inventory": 12,
  "updatedAt": "2026-10-17T10:00:00+08:00"
}
```

## 2. 推荐时的高效调用顺序

不需要对全部 200 多门课逐条查询详情：

1. 拉取一次完整课程列表并建立本次目录快照。
2. 按日期、列表状态与基础字段做第一轮硬过滤；当前 MVP 到此即可确定可用候选。
3. 用灵数、脉轮和罗盘连接倾向打分，召回前 10-15 门。
4. 库存能力启用后，再只对这 10-15 门按 `elementId` 查询详情、售卖状态与库存。
5. 届时剔除不可用课程；不足三门时继续向后补候选。
6. 最终返回三门，并把本次目录版本、详情检查时间和场次 ID 写入推荐快照。

## 3. 三张卡的排序职责

- 第一张：匹配分最高，优先保证准确性。
- 第二张：仍以匹配为先，同时避开与第一张重复的主要脉轮或练习形式。
- 第三张：只在匹配分达标的候选中照顾低曝光课程。

当前下架与过期过滤属于硬条件，不参与打分，也不能被“公平曝光”重新加回。售罄过滤待正式接口补齐后启用。

## 4. 2025 回溯验证口径

- 内容召回覆盖率使用完整 2025 历史课程，验证标签和匹配逻辑。
- 另用 2025-10-24 至 2025-10-26 的活动时刻模拟场次过期，验证旧场次会退出。
- 这只是历史 QA 模式；正式上线始终使用请求时刻判断场次是否已经结束。

## 5. 验证命令与年份隔离

用已有标准化目录离线复算，不访问或覆盖其他年份：

```bash
python3 scripts/validate_course_recall.py \
  --catalog-file qa/course-recall-2025/catalog-normalized.json \
  --catalog-label "HAF 2025"
```

从接口拉取新目录时，活动 ID 和目录标签必须明确包含同一年份；未指定输出目录时，脚本写入 `qa/course-recall-{year}/`：

```bash
python3 scripts/validate_course_recall.py \
  --event-id "HAF 2026" \
  --catalog-label "HAF 2026"
```

禁止把 2026 API 结果写入 `qa/course-recall-2025/`。场次模拟检查点从目录实际日期生成，不再在代码中硬编码年份。
