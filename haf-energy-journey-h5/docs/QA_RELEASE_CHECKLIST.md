# HAF 探索本心：QA、快照与发布清单

版本：v4.1
日期：2026-08-29

## 1. 自动检查

```bash
npm run release:check
node --check ../haf-energy-dashboard/server.mjs
```

`npm run test:runtime` 需要本机 Playwright Chromium；若缺失，记录环境限制，不将它误报为产品失败。

## 2. 入口与建档

- Loading 无矩形遮罩或异常透明块
- 小程序负责介绍/回访入口；H5 不再出现旧三步介绍或问候页
- 用户资料状态为 `missing` 时进入建档，`ready` 时直接进入感应
- 点击年份后原位出现四位数字输入，完成后保持原有大号排版并收起键盘
- 6 月 29 日等日期可选，闰年 2 月 29 日可选
- 城市可自由输入并保存
- 保存后进入感应页

## 3. 回访、声音与缓存

- 回访不重复建档
- 环境音乐在感应、合成、结果、收藏和资料修改间连续，不因切页重启
- 冥想引导同一自然日最多一次；重新感应不重复旁白
- 引导播放期间不允许提前锁定词，结束后才开放感应
- AI 解读超过 6 秒时使用本地结果且不在结果页内二次跳字
- 修改生日使 Life Path 或 Personal Day 变化时，不复用旧解读签名

## 4. 感应与结算

- 小球可按住并拖动；快速轻点只解锁声音，不直接锁词
- 按压移动期间不展示候选词，松手后才慢慢显现最终词
- 隐藏词场每轮随机偏移/镜像，绝对坐标不永久对应同一个词
- 松手后的词、主脉轮、结果标题和推荐理由保持同一条证据链
- 合成 Loading 中完成 AI 请求
- 结算页出现后解读文字、位置和高度保持稳定
- 普通内容 14px，非课程卡最小 12px
- 结果引导句使用完整宽度，不出现单个汉字孤行
- 光球无矩形背景遮罩

## 5. 课程与收藏

- 恰好三张课程卡
- 每张有图片、名称、契合理由、真实场次时间/形式和收藏按钮
- 不显示价格或购买压力
- 收藏和取消收藏状态正确
- 圆形收藏入口进入独立收藏页，并显示数量
- “重新感应”返回已有感应路由，不形成死循环
- 返回后旧词、白色锁定点和完成按钮均清空，小球回到中性起点

## 6. 接口与看板

- AI Key 不出现在 H5 构建产物
- AI 接口不接收生日、性别、城市
- 页面在 4174 不可用时仍可完成
- 三项感应媒体均存在于 `dist/client/assets/haf/sensing/`，且与源文件大小一致
- 一次模块打开只记录一次访问事件
- 一次成功收藏只记录一次收藏事件
- 看板访问用户、收藏用户和收藏总量可抽样核对

## 7. 快照规则

- 快照目录使用 `YYYY-MM-DD-名称-vN`
- 包含 H5 源码、锁文件、资产、Skills、docs、QA 证据和后端源码
- 排除 `node_modules`、`dist`、`test-results`、`.env.local`、`data/*.jsonl`、系统文件和临时日志
- 快照根目录必须有 README，说明范围、校验值和恢复方法
- 快照创建后只读，不在其中继续开发
