# HAF 灵数规则复核

日期：2026-08-27
适用版本：`haf.numerology.v1`

## 结论

- 结果页的“今日灵数”是 `Personal Day`（个人日数），范围固定为 1–9；它不是生命路径数。
- 现有 Personal Day 公式与项目采用的西方灵数算法一致：出生月 + 出生日 + 当年 + 当月 + 当日，持续归并到一位数。
- 生命路径数继续使用出生年月日分段归并，并在该层保留 11、22、33；它只参与背景权重，不显示在“今日灵数”卡片中。
- 数字含义属于象征性解释，不是科学测量或预测。
- 旧版把数字显示词直接复用了脉轮关键词。5 显示为“流动”并非完全错误，但它更接近 HAF 的生殖轮语言，容易让人误以为“数字 5 = 某个脉轮”。本次将每日数字显示词与脉轮词拆开。

## 1–9 展示词

| Personal Day | 页面展示 | 采用的含义范围 |
| --- | --- | --- |
| 1 | 开始 | 独立、主动、开创 |
| 2 | 连接 | 合作、感受、协调 |
| 3 | 表达 | 创造、沟通、轻盈 |
| 4 | 安定 | 结构、秩序、建构 |
| 5 | 变化 | 自由、移动、适应 |
| 6 | 关怀 | 责任、照顾、和谐 |
| 7 | 内省 | 求索、分析、智慧 |
| 8 | 实现 | 目标、力量、平衡 |
| 9 | 完成 | 慈悲、整合、释放 |

这些词是 HAF 对常见含义的简短产品化表达，不宣称是唯一或传统固定译名。

## 层级边界

1. `Personal Day` 只提供“今日节律”和 10% 的脉轮辅助权重。
2. 用户松手选中的 70 词之一决定主脉轮，证据权重为 70%。
3. 生命路径数提供 20% 的长期背景权重。
4. 页面展示词不得与 70 个感应词完全相同，避免出现“算出来的词”和“用户选中的词”重复。
5. 数字展示词不直接等于脉轮，也不能作为课程召回的硬条件；课程仍先匹配用户选词对应的主脉轮。
6. 课程 `keyword_tags` 只能来自课程标题、简介和官方标签；不能再由 `numerology_tags` 转写，以免同一数字证据在“选词匹配”和“灵数匹配”中重复计分。

## 自动检查

运行 `npm run check:numerology`，验证 1–9 均有唯一展示词、均有合成映射，并且不与 70 个感应词重复。
