# 正式接口接入清单

版本：v1.1
日期：2026-08-29

## 0. 用户资料与入口

- 小程序负责登录、介绍/回访入口和 WebView 容器。
- H5 先请求用户资料状态；只有 `missing` 才显示建档，`ready` 直接进入每日感应。
- 当前本地完成标记只是临时适配器，正式用户信息接口接入时不要恢复旧的 H5 介绍或问候页。
- 资料提交成功后再切换 `profile_status`，并由后端保存真实用户资料。

## 1. 课程接口

必须提供：

- 稳定 `course_id`
- `title`
- `cover_asset` 或图片 URL
- `duration_min`
- `format_label`
- `short_description`
- 发布与可用状态

建议提供：

- 学习目标或体验结果
- 难度与能量强度
- 内容标签
- 安全提示与不适用情况
- 内容版本号

接入时只替换课程数据适配层，不修改灵数、罗盘、脉轮和推荐的核心流程。

## 2. 收藏接口

收藏请求至少包含：

- 用户 ID
- 课程 ID
- 来源 `energy_journey`
- 客户端请求 ID，用于防止重复提交

成功响应至少包含：

- `favorite_id`
- `course_id`
- 最终收藏状态
- 服务端时间

只有接口确认成功后，才更新按钮为“已收藏”并记录 `energy_course_favorited`。失败时保留原状态，并给出轻提示。

## 3. DeepSeek 接入

正确链路：

```text
H5 → HAF 后端 → 规则与课程服务 → DeepSeek
```

当前 H5 使用：

- `POST /api/energy-reading`
- H5 端 6 秒超时
- Loading 阶段请求与页面前锁定
- 本地规则回退

`POST /api/daily-greeting` 仅是旧入口页的历史接口；当前 H5 不调用它。若小程序入口需要问候，应由小程序或入口服务独立接入，不能据此在 H5 恢复旧页面。

生产要求：

- Key 只保存在服务端密钥管理中
- 每个用户流程的模型调用次数需有预算、监控与限流
- 真实课程接入后，优先让一次结算请求返回总结与三条推荐理由
- 只能引用结构化能量事实和真实课程介绍
- 只能选择已过滤的候选课程 ID
- 返回结果必须通过 JSON Schema 与证据标签校验
- 设置超时、有限重试、缓存和规则模板回退
- 缓存键必须包含用户、日期、Personal Day、Life Path、罗盘结果签名、规则版本、提示词版本和课程版本中与该输出相关的字段
- 修改资料后不得复用旧计算输入对应的缓存

## 4. 数据埋点与看板

H5 环境变量：

```text
VITE_HAF_ANALYTICS_ENDPOINT
```

生产环境必须将它指向 HAF 后端，而不是本地 4174 服务。

当前最小事件：

- `energy_module_viewed`
- `energy_course_favorited`

看板只读取聚合数据，不需要读取用户生日、罗盘坐标、灵数、脉轮或完整推荐理由。

正式看板必须：

- 使用登录鉴权
- 只允许有权限的运营或产品人员访问
- 使用数据库而非本地 JSONL 文件
- 处理事件去重
- 统一服务端时区和自然日边界

## 5. 上线前验收

- iPhone 与 Android 小程序 WebView 实机验证
- 首次与回访流程验证
- Personal Day 跨自然日切换验证
- 课程接口异常与空列表验证
- 收藏重复点击、失败、撤销验证
- DeepSeek超时和回退验证
- 埋点失败不影响主流程
- 看板数字与数据库抽样核对
- 隐私说明和档案删除能力确认
- 旧版快照可独立恢复
- 能量解读必须在结果页出现前锁定，网络晚到不能造成文字跳动
- 对话中曾公开的 DeepSeek Key 已吊销并更换
- 生产密钥不出现在前端构建、日志、截图、埋点或版本快照

详细请求体和响应体见 `API_CONTRACTS.md`；完整验证步骤见 `QA_RELEASE_CHECKLIST.md`。
