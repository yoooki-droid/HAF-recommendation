# HAF 探索本心：隐私与 AI 边界

版本：v4.1
日期：2026-08-29

## 1. 收集目的

- 生日：计算生命路径与每日数字。
- 出生时间、性别、城市：当前 Demo 可选展示资料，尚未进入生命灵数核心公式。
- 感应落点与锁定词：记录用户此刻的主观选择，仅用于当次能量合成。

如果正式产品不使用出生时间、性别或城市，应删除采集，不为了“看起来更准”而保留无用信息。

## 2. 发给 DeepSeek 的内容

允许：

- 匿名用户键
- 日期和已计算数字
- 已锁定的词 ID、显示词和所属 HAF 脉轮
- 已计算的主次脉轮名称与主题
- 真实课程事实和安全标签（未来）

禁止：

- 姓名、手机号、登录凭证
- 完整生日、出生时间、性别、城市
- GPS、通讯录、聊天记录
- DeepSeek API Key
- 医疗、心理诊断或其他敏感档案

## 3. 表达边界

允许：

- “今天可以留意……”
- “你可以把它当作一次轻轻的询问。”
- “此刻更适合……”

禁止：

- 命中注定、必然、将会发生
- 好运、坏运、灾难预警
- 脉轮堵塞、能量疾病、治疗承诺
- 创伤、人格、抑郁、焦虑等诊断
- 用课程替代专业医疗或心理帮助

## 4. Key 管理

- Key 只能存在服务端密钥管理或本地 `.env.local`。
- `.env.local` 必须被忽略，不能进入版本快照。
- 不在日志、埋点、截图、文档或聊天中重复展示 Key。
- 对话中曾公开的 Key 在正式上线前必须吊销并轮换。

## 5. 数据删除与授权

当前 Demo 的“修改资料”不是完整删除能力。正式版需提供：

- 清除出生档案
- 清除历史感应结果
- 清除收藏或跳转到统一收藏管理
- 撤回个性化授权
- 查看隐私说明和数据保存期限

## 6. 看板最小化

数据看板只保存匿名访问和收藏事件，不保存生日、数字、感应坐标/词、脉轮、AI 解读或推荐理由。正式看板必须有登录、角色权限和聚合展示。
