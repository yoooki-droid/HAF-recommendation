# v3 UI/UX 基线与下一轮优化边界

版本：v3.0  
日期：2026-08-23

## 目标

下一轮可以继续提升视觉精度、可读性、仪式感和操作反馈，但不能破坏当前已经验证的流程与数据行为。

## 当前必须保留

- H5 为小程序首页内嵌模块，高度约 700px
- 整体左右贴边，无外层圆角框
- 蓝色主氛围与少量暖橙光流
- 首次进入使用“三步玩法介绍”，让用户理解天生线索、此刻感应和今日回响
- 回访页为纯文字问候，不重新加入大能量球
- 每日问候只使用 Personal Day 已知信息
- 罗盘仍是一次直接的手指感应，不恢复重复问题
- 结算页同时保留今日主旋律、此刻入口、能量落点和今日能量总结
- 结算页能量球只占标题角落，引导句拥有完整文字宽度，避免单个汉字掉到新行
- AI 文案在 Loading 阶段确定；展示页内不得再异步替换造成跳动
- 推荐引擎仍固定返回三条课程记录，但界面以“此刻与你契合的体验”承接能量叙事，不突出“3 节课”；横向卡片保留小图、契合理由、日期、时间/形式和收藏
- 独立收藏页必须保留
- “重新感应”返回现有罗盘，不新建重复页面层级
- 埋点与接口失败不能阻断体验

## 可优先优化的方向

### 1. 首次建档

- 验证三步介绍是否足以让新用户理解并愿意开始
- 进一步明确生日参与核心计算，其他字段目前为可选资料
- 提升生日选择的直觉性
- 把隐私说明变得更温柔、更短

### 2. 每日问候

- 检查 1–9 的文案节奏是否同一品牌声音
- 继续扩充最近 30 条问候的语言多样性
- 优化主句断行和进入动画

### 3. 罗盘

- 增强手指落点和光球被吸引过去的感受
- 优化四个方向词的可读性
- 让“完成感应”在用户真正触碰后再明显出现

### 4. 合成动画

- 保持无矩形遮罩
- 更清楚地表现数字、脉轮和此刻能量正在靠近
- 真实 AI 响应较慢时提供有节奏的进度文案，但仍以 6 秒为硬上限

### 5. 结算页

- 优化信息层级与留白
- 检查三条能量线索是否一眼可读
- 让今日总结更像一句真正属于用户的话
- 保证课程理由在小屏宽度下仍然舒适
- 保持语言层次：上半段是“今日能量”，推荐区是“此刻契合”；单个项目按形式称为“这段冥想练习”“这场声音体验”等，不使用目录式的“这节课”

### 6. 收藏页

- 增强“收藏正在形成个人路径”的感受
- 保持不催促购买
- 为未来课程详情入口预留清晰位置

## 暂不扩大范围

- 不增加复杂问卷
- 不增加购买价格与销售压力
- 不增加脉轮诊断或健康结论
- 不把数据看板扩成复杂运营后台
- 不在 UI/UX 优化阶段改动算法权重
- 不改动当前“灵数”展示命名，除非产品统一重新定义生命路径数与今日个人数的对外术语

## 每轮验收

每次 UI/UX 修改后都需要重新走完：

```text
回访问候 → 罗盘 → 合成 → 结算 → 收藏 → 收藏页 → 返回 → 重新感应 → 第二次结算
```

并检查 H5 访问与一次收藏在看板中只增加一次。
